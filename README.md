# 島鏈補給（pg-islesupply）

十回合島鏈物流策略遊戲：看兩輪風向與颱風預報，替三艘船安排卸貨、裝貨與下一站，維持七座有人島的糧食、藥品與燃油供應。

## 執行

本遊戲是無 build 的純 HTML／CSS／JavaScript SAM。

```sh
python3 -m http.server 4173
```

開啟 <http://localhost:4173>。

## 測試

```sh
npm test
```

測試涵蓋船艙容量、卸裝順序、抵達時點、倉儲溢出、消耗順序、連續缺貨敗北與風向航程等核心規則。不要提交 `node_modules`。

## 規則摘要

- 七座島每輪消耗 1～2 箱糧食、藥品與燃油。
- 中央港大量生產三物資；六座外島每輪生產 1 箱特產。
- 三艘船有不同船艙與航程上限。靠岸時先卸後裝，再依命令出航。
- 所有命令同輪結算；抵達後下一輪可卸貨，卸貨會在該輪消耗前入庫。
- 順風縮短、逆風延長航程；颱風成形時本輪出港航程增加一回合。
- 任一島連續兩輪缺任一關鍵物資即敗；全島維持十輪即勝。
- 最佳分數與解鎖船旗分別保存於 Playgrounds KV `islesupply:best`、`islesupply:unlocks`。
